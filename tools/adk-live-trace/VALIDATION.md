## What the tests establish

The logger tests check PCM byte counting for base64, binary values and arrays; malformed input omission; preservation of ordinary business data; credential masking; no mutation of the input JSON; 800 records from eight concurrent threads; sequence and timestamp formatting; transcript flags without inferred finality; JDBC result/exception preservation and actual commit/rollback observation; registry collisions and cleanup; transport shutdown waiting; file isolation; and failure reporting for late writes.

The SDK integration tests invoke the real SDK converters and WebSocket callback code with a recording socket and mocked ApiClient. They check that the actual setup is observed, setupComplete is captured before consumption, pre-callback messages remain visible, interruption reaches the callback, the 640-byte PCM send is unchanged while its log representation omits the payload, invalid initial responses fail setup, and close tracking finishes. They do not open a network socket.

The browser test injects a send function and clock; it does not run an AudioWorklet or measure a speaker. JDBC tests use a mock connection; they do not establish PostgreSQL durability in a live deployment.

## Runtime acceptance still required

No configured Gemini model, PostgreSQL/Redis service, microphone or application player was exercised. Run the acceptance sequence in [README.md](README.md) against your application. In particular, actual server speech detection time and speaker playback time cannot be recovered from a local Java callback timestamp. Buffer-clear and transcript-edit records require the application's real operations to be instrumented.

The logger observes existing behavior. It does not implement model compatibility, tool cancellation, reconnection/resumption, browser playback, or database transaction repairs.

## Reproduce the focused ADK check

After installing the logger and patched SDK, from the pinned ADK root:

```sh
mvn -N install
mvn -f core/pom.xml -Dtest=GeminiLlmConnectionTest,LlmRequestTest,InputAudioTranscriptionTest,RunnerTest install
```

Building core directly avoids resolving unrelated reactor tutorials and integrations. The repository's formatter ran on the changed core and dev files; the delivered patch incorporates its formatting. After core installation, the adapter compile/package check was `mvn -f dev/pom.xml -DskipTests package`.
